# Precedent — frontend (PWA)

Owned by the frontend teammate. Desktop-first (≥1280px), fully responsive down to phones.

Stack: Vite 8 · React 19 · TypeScript · vite-plugin-pwa (`injectManifest`) · Tailwind v4 · shadcn/ui ·
TanStack Query + Table · Zustand · React Router 7 · Recharts · openapi-typescript + openapi-fetch.

Start here: [`../docs/api-contract.md`](../docs/api-contract.md) and the mocks in [`../docs/mocks/`](../docs/mocks/).
